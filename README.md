# 交运题练 · 2026 知识竞赛

依据提供的《2026年知识竞赛题库.wps》制作的刷题网站，适配电脑与手机。

**在线使用：<https://cmysdd.github.io/transport-quiz-2026/>**

## 题库

共 **308 道题**：142 道单选、113 道多选、53 道判断。

| 分类 | 题量 |
| --- | ---: |
| 综合类 | 70 |
| 道路运政 | 139 |
| 路政 | 75 |
| 安全、海事、工程质量 | 24 |

道路运政原文中的题号 33、41 各出现两次。网站保留全部题目，使用独立 ID 和分类内序号，同时保留原题号以便核对。题干、选项和标准答案依据原题库；仅整理排版、空格和选项分隔符。原题库未提供文字解析，网站展示标准答案与作答对照。

## 功能

- 背题模式：直接显示题干、标准答案及正确选项全文，支持分类、题型和关键词筛选、分页阅读，也可从错题本或收藏进入。
- 顺序练习、随机练习、每日最多 20 道未练题目。
- 按分类、题型、未练状态和关键词筛选；关键词同时搜索题干和选项。
- 单选、多选、判断题。多选题必须全部选对。
- 错题自动收录，再次答对后移出；重点题目可收藏。
- 模拟考试自选分类、题量及时间，随机组卷，交卷后显示成绩和逐题答案。
- 考试以绝对截止时间计时，刷新或返回其他页面后可继续，超时自动交卷。
- 学习进度、作答统计和考试记录保存在当前浏览器，支持 JSON 备份导入、导出。
- 首次联网加载完成后，可通过浏览器缓存离线练习。

模拟考试按答对题数折算为百分制，未答题计为错误；该计分方式用于练习，不代表正式竞赛规则。记录不跨设备自动同步，可以通过导出和导入迁移。

## 本地运行

无需安装依赖。安装 Node.js 18 或更新版本后运行：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173>。也可以直接打开 `index.html`，但离线缓存功能需要 HTTP 服务。

```sh
npm test       # 验证题库、评分、错题恢复、备份和计时
npm run build  # 输出可部署的静态文件至 dist/
```

## 部署

GitHub Pages 使用 `.github/workflows/pages.yml`，推送 `main` 后自动测试和部署。仓库的 Settings → Pages → Source 应设为 **GitHub Actions**。

也可将 `dist/` 上传至任何静态网站托管服务。所有资源使用相对路径，支持部署在子目录。

## 更新题库

原始 WPS 文件和中间导出文件留在本地，不提交至仓库。若需重新生成题库，将原始文件放在项目根目录，Windows 上安装兼容的 Word COM 组件后运行：

```powershell
pwsh -STA -File tools/extract-question-bank.ps1
npm run parse
npm test
```

整理脚本在识别到缺失答案、选项异常时终止，并在 `.source/` 输出审计结果。更新页面资源后，请同步提升 `sw.js` 的缓存版本。
